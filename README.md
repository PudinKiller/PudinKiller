## Featured Tools

### [VFX Mesh Lab](https://github.com/PudinKiller/VFXMeshLab)

A Unity 6 URP editor tool for generating and art-directing procedural VFX meshes. It includes 14 shapes, ordered modifiers, UV and vertex-data authoring, live diagnostics, reference-preserving updates, and 102 automated Edit Mode tests.

[Repository](https://github.com/PudinKiller/VFXMeshLab) · [Launch Demo](https://www.linkedin.com/feed/update/urn:li:activity:7488642067171225600/)

### [VFX Texture Lab](https://github.com/PudinKiller/VFXTextureLab)

A Unity 6 editor tool for batch VFX texture processing with stackable operations, live previews, gradient mapping, mask cleanup, channel packing, and data-aware PNG/EXR output.

[Repository](https://github.com/PudinKiller/VFXTextureLab) · [Launch Demo](https://www.linkedin.com/feed/update/urn:li:activity:7465088710020079616/) · [Featured by Jettelly](https://jettelly.com/blog/vfx-texture-lab-making-texture-edits-without-leaving-unity)
